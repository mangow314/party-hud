# CLAUDE.md

Commands and ground rules: `CONTRIBUTING.md`. Design: `docs/architecture.md`. Per-agent data: `docs/integrations.md`.

## Running checks

- `tests/party-tmux-test.sh` needs a real tmux socket and fails inside the Claude Code sandbox; ask the user to run
  `! bash tests/party-tmux-test.sh`.
- No per-test filter: run all of `bash tests/party-test.sh` (about 2 s) and grep its output for `FAIL`.
- Before done, run: `ruff check . && ruff format --check . && basedpyright . && bash tests/party-test.sh`.
- Code must run on Linux and macOS (CI runs both): `/proc` exists only on Linux, macOS goes through `ps`.
- Local runs cover one OS only; macOS differences (`ps` output, locale, Python's `Python.app` re-exec) show up only in
  CI. On a branch that will run for more than a commit or two, push early and read the `macos-latest` job each push.

## Guardrails

- `party.py` and `party_hud/` use only the Python 3.10+ standard library. Pillow / NumPy only under `scripts/`.
- Read only: the HUD (sidebar, collector, report pane) only reads; the summon, send and dismiss subcommands open panes, send keys and close panes they opened only when an agent explicitly calls them; the restore subcommands replace the shell of a pane with a sidebar only when a layout saver's hook names its place and the pane was made after `--restore-begin`; never write to an agent's files, never use the network under any circumstances.
  (HUD（側欄、collector、回報 pane）只讀；召集、送出和解散的子指令只在 agent 明確呼叫時，才開 pane、送按鍵和關掉自己召喚的 pane；還原的子指令只在存檔還原外掛的 hook 指名位置、而且那個 pane 是 `--restore-begin` 之後才建立時，才把它的 shell 換成側欄；任何情況都不寫 agent 的檔案、不走網路。)
- A change that adds work per frame or per collection needs `python3 bench/bench.py` numbers before and after.
- No comments by default. Allowed only for what the code cannot show: outside behavior a line depends on (tmux,
  terminal, OS, Python, an agent), a constraint set elsewhere in the code, the name of an opaque value, a lint
  suppression with its reason. English, one line, says why. A design choice goes in a test or `docs/architecture.md`.
  Update or delete a comment in the same change as its code, but never delete one without checking that the
  behavior it guards no longer applies. Docstrings only where the name does not make the interface clear.
- `party_hud/` modules import only earlier ones: `common` -> `art` -> `collect` -> `render` -> `sidebars` -> `ui`.
  `render.py` stays pure (snapshot in, text out).
- A sidebar out of view exits after 2 s, so hidden windows have no sidebar process. Work that must happen for hidden
  windows (bells, closing sidebar-only windows) belongs in the collector or a tmux hook, not the sidebar loop.
- Only the process holding `snapshot.lock` collects; the others reuse the old `snapshot.json` and never wait on it.
- Every card line must be exactly the drawable width (33 columns by default), CJK = 2, combining marks = 0.
- `art/` is generated by `scripts/art/` (see `ASSETS.md`). New art must be CC0-compatible and must not imitate a
  specific existing game, character or artist.
- When user-visible behavior changes, update both `README.md` and `README.zh-TW.md`.
